DOCUMENT STATUS

A React SPA backed by one event-driven Lambda.

CloudFront serves the browser app and forwards API requests to API Gateway. Cognito verifies member identity. One Node.js Lambda handles HTTP requests, asynchronous cover-letter work and the daily job-feed refresh. DynamoDB is the source of truth; S3 holds the site and short-lived resume originals.

CONFIDENCE AND RISK

What the source proves

Verified

  • Guest search stores at most 30 high-fit jobs and exposes five at a time.
  • Interested creates an application only after server-side revalidation.
  • Stripe query parameters never grant entitlement; the server re-fetches canonical Stripe state.
  • Successful letters consume allowance. Definitive failures release it.
  • Guest browser state excludes resume and job-description content.
  • The scan excluded private runtime folders, resumes, databases, build output and credentials.

Open or structural risks

  • src/App.jsx is a 4,399-line controller and change hotspot.
  • The member app has no commit provenance while it remains untracked.
  • The directory defines builds and CloudFormation preparation but no deployment or CI command.
  • contract.json and server work-rights values need reconciliation.
  • Provider health and deployed parameter values require a separate live-system check.
  • The source permits an external-AI policy envelope up to US$5 per Sydney day; effective approval is runtime state.
